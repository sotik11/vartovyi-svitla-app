# Промо: превью й опис для допису

- `post-horizontal.png` (1600×900) і `post-vertical.png` (1226×1440) — превью.
- `post_horizontal.py` / `post_vertical.py` — збирають їх: сова з `docs/hero.webp`, чотири екрани.
- `shots/` — готові кадри, вже без системних смуг і реальних адрес:
  `shot_home.jpg` (Головна, 12 год), `shot_summary.jpg` (Зведення), `mixed_09.jpg` (віджети: темний фон + два світлі).
  Другий екран береться з `docs/screenshots/light/08.jpg`.

Перезібрати (потрібні Pillow і numpy, шрифти Segoe UI з Windows):

```
python docs/promo/post_horizontal.py
python docs/promo/post_vertical.py
```

Новий кадр: телефонний скрин 591×1280 → обрізати `(0, 66, 591, 1203)`, замалювати реальну адресу
(місто, ЖК, канал → «Моє місто», «Мій ЖК»), покласти в `shots/` і вписати в список `shots` скрипта.
Сирі скрини сюди не кладемо: `docs/` цілком іде на публічну вітрину.
